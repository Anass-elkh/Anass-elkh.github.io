## 📌 Présentation

Ce portfolio interactif regroupe l'ensemble de mes réalisations logicielles, projets de recherche appliquée et contributions en entreprise :
- **Lear Corporation (PFE)** : Système Intelligent de Gestion des Terminaux Industriels & Démarche Lean Kanban.
- **SOUYIE H66PRO** : Vitrine interactive horologique 3D avec scrubbing vidéo synchronisé (React 19 & Three.js).
- **INFODIX SARL** : Application de Gestion de Stock temps réel (React, Node.js, Redis, PostgreSQL, Docker).
- **Al Omrane** : Plateforme de support Helpdesk & Ticketing.
- **Data Analytics & BI** : Modélisations de risque crédit bancaire et tableaux de bord e-commerce (Power BI, Tableau, Excel VBA, SQL).
- **Services Web Distribués** : Gestion académique JEE (REST JAX-RS & SOAP JAX-WS).

## 🚀 Démarrage Local

```bash
# 1. Cloner le dépôt
git clone https://github.com/Anass-elkh/Anass-elkh.github.io.git
cd Anass-elkh.github.io

# 2. Installer les dépendances
npm install

# 3. Lancer en local
npm run dev
```
